## README 与这些文档的分工

README 只保留**能做决定的长度**：一段定位、一张安装命令、一张功能表、一张工具表、一份限制清单。凡是需要展开论证的（为什么这样设计、为什么不做某个功能、某个边界为什么在那里），都在这里。

**功能对照**那份是机器生成的判据：它逐条到代码里查符号，不凭记忆。改完代码跑一次就能看回归：

```sh
node scripts/audit-against-research.mjs
```
